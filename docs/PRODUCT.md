# Inspira Product

## 产品定位

Inspira 是私人灵感收集与再发现工具。用户可以从 Chrome 插件保存网页、图片和选中文字，也可以在 Web 创建笔记并插入图片；之后通过 All 卡片流、关键词过滤、标签、工作区和 Insights 找回内容。

## 产品模块

| 模块              | 当前职责                                                       | 边界                         |
| ----------------- | -------------------------------------------------------------- | ---------------------------- |
| Identity          | Clerk 登录、退出、会话过期处理；服务端按会话确定 owner         | 不做自建密码系统             |
| Landing           | 产品介绍、登录入口、隐私说明                                   | 不放未确认的商店或下载地址   |
| All               | 本人全部灵感卡片流、关键词过滤、视图密度、详情、编辑、删除     | 不做语义搜索、收藏或公开分享 |
| Notes             | Web 创建/编辑 Note；支持在正文中插入受管图片                   | 不做复杂协作富文本           |
| Content Types     | page、image、quote、note、video 五类数据类型和展示兼容         | 当前写入入口不包含视频上传   |
| Workspaces        | 工作区列表、创建、重命名、删除、0..N 归属调整、单区专题流      | 不做共享工作区或协作权限     |
| Tags              | 字符串标签输入、展示和统计聚合                                 | 不做全局 tagId 模型          |
| Extension Capture | Chrome 插件保存当前网页、右键图片、右键选中文字                | 不做视频采集                 |
| Media             | Page 快照、采集图片和 Note 图片的受管存储、绑定和短时访问      | 不做视频转码或 CDN 优化      |
| Insights          | 365 天热力图、总量、本周新增、最长连续记录、类型构成、Top 标签 | 不做收藏统计或旧内容回顾     |
| Settings          | 浅/深主题、自定义主色、默认视图、账户与插件状态展示            | 当前不做偏好跨端同步         |

## 页面与交互

| 页面/入口   | 行为                                                                  |
| ----------- | --------------------------------------------------------------------- |
| Landing     | 未登录用户看到产品介绍、登录入口和隐私说明                            |
| All         | 登录后默认进入；展示全部本人灵感，可关键词过滤、切换 4/5 列、打开详情 |
| Workspaces  | 展示工作区总览；可创建、重命名、删除工作区；进入单个工作区专题流      |
| Insights    | 展示本人当前内容集合的统计，不包含收藏或回顾类指标                    |
| Settings    | 管理本地主题偏好、主色和默认视图；展示账户与插件状态                  |
| Chrome 插件 | 点击图标保存当前网页；右键图片保存 Image；右键选中文字保存 Quote      |

导航已确认：All 使用固定窄侧栏，Inspira 作为侧栏品牌入口并返回 All，包含 Insights、浅/深切换和 Settings。All 与 Workspace 从右上角栏目进入。Insights/Settings 进入后使用独立页面布局并提供返回。

详情已确认：点击卡片在当前流上打开浮层；左侧展示图片、网页快照或内容主体，右侧展示标题、Tags 和单独的 Notes 备注。图片直接可见；page 快照通过受管短时地址展示。

## 内容与媒体规则

内容类型：

- Page：来源 URL、页面标题、来源域名、可读文本摘要、受管 HTML 快照。
- Image：采集图片的受管文件、来源 URL、可选标题和备注。
- Quote：选中文字、来源 URL、页面标题、可选备注。
- Note：Web 创建的正文、可选标题、可选受管图片引用。

共同字段：owner、type、title/content 等类型字段、可选 notes 备注、tags、可选 workspaceIds（最多 12 个）、创建/更新时间。

媒体访问已确认：登录并通过所有权校验后签发短时地址；详情内直接看图或展示网页快照，过期后重新授权。当前受管媒体覆盖 Page 快照、采集图片和 Note 图片。

## 写入全流程

| 阶段        | 负责人            | 产物                                                  | 进入下一步的条件                                    |
| ----------- | ----------------- | ----------------------------------------------------- | --------------------------------------------------- |
| 1. 产品定义 | Owner             | 本文档中的目标、边界、页面入口、内容规则和不做项      | 行为已写清，未定项有阻塞范围                        |
| 2. 方案设计 | Miora             | 对应页面/流程设计、状态覆盖、交互细节和视觉规则       | loading/empty/error/success、响应式和关键边界已覆盖 |
| 3. 编码实现 | CodeBuddy         | Web、Extension、Convex、contracts、测试和必要文档更新 | 代码按现有架构落地，不扩大未授权范围                |
| 4. 验证验收 | CodeBuddy + Owner | lint/build/test 结果、人工验收记录、已知缺口          | 真实命令通过；不能用空测试或未运行 CI 当证据        |
| 5. 状态同步 | CodeBuddy         | `docs/`、OpenSpec tasks、必要的交接说明             | 文档只声明已验证能力，不把规划当完成                |

模块写入规则：

- Miora 负责设计，不直接定义后端契约或改业务代码。
- CodeBuddy 负责编码，不自行扩展产品范围；遇到阻塞产品行为时回到产品定义确认。
- 原型和设计稿是实现参考，不自动成为已上线能力。
- 契约变化必须同步 `packages/contracts`、Convex、调用端、测试和 `docs/CONTRACTS.md`。
- 每次模块写入都要保留明确的不做项，尤其是 AI、协作、公开分享、收藏、旧内容回顾和视频能力。

## 实现顺序

每个阶段对应一个 OpenSpec change，只实现本阶段范围。

| 顺序 | Change                                   | 交付模块            | 主要任务                                                       |
| ---- | ---------------------------------------- | ------------------- | -------------------------------------------------------------- |
| S0   | `establish-project-baseline`           | 文档与协作基线      | 修订产品与工程文档；建立模块流程映射、决策台账和实现状态       |
| S1   | `establish-engineering-checks`         | 工程检查            | 接通真实检查、测试和 CI；补契约测试                            |
| S2   | `implement-note-core`                  | Identity、All、Note | Clerk 接入；后端用户隔离；创建 Note；All 展示；详情浮层        |
| S3   | `implement-workspace-interactions`     | Workspaces          | 工作区总览预览、创建入口、归属管理                             |
| S4   | `support-multi-workspace-inspirations` | Workspaces、All     | 单工作区归属升级为 0..N membership；Web 多选归属入口           |
| S5   | `implement-extension-capture`          | Extension Capture   | 插件登录衔接；点击保存网页；右键保存图片和选中文字；同请求重试 |
| S6   | `implement-managed-media-snapshots`    | Media、Page         | 受管媒体与网页快照底座；图片转存；快照详情渲染                 |
| S7   | `implement-hardened-media-access`      | Media               | 媒体访问边界：鉴权读取端点、存储适配层、清理与撤销             |
| S8   | `implement-insights`                   | Insights            | 统计查询；独立页面外壳；热力图、摘要、类型构成和趋势           |
| S9   | `implement-preferences-settings-theme` | Settings            | 设置页面；主题模式；自定义主色与十色阶                         |
